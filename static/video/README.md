# 背景视频

当前使用的文件：`bg.mp4`

| 项目 | 值 |
|---|---|
| 内容 | 意大利肉酱面摆盘 |
| 分辨率 | 1280 × 720 |
| 时长 | 13 秒（循环播放） |
| 体积 | 4.7 MB |
| 编码 | H.264（avc1）—— 所有浏览器都支持 |
| 来源 | Mixkit，免费可商用，无需署名 |

## 换成你自己的视频

直接把文件替换掉即可，**不用改代码、不用重启服务**，刷新页面就生效：

```bash
cp 你的视频.mp4 ~/PycharmProjects/FastAPIProject3/static/video/bg.mp4
```

建议：

- **格式必须是 MP4（H.264）**，兼容性最好；WebM 在 Safari 上可能不播
- 时长 10–30 秒，能无缝循环最好
- 分辨率 1280×720 以上，横屏
- 体积 ≤ 15MB

## 页面会怎么处理它

- 自动静音 + 循环 + **0.55 倍速慢放**
- 盖一层浅色渐变遮罩，保证文字读得清
- 没有视频文件时，自动改用「缓慢飘动的热气」动态背景
